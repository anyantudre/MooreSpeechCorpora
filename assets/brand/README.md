# FasoSpeechCorpora logo

The logo is a balafon, the wooden xylophone with calabash gourds played across Burkina Faso, where FasoSpeechCorpora started with Mooré. The main logo shows the whole instrument with its mallets. The round seal puts the same drawing in a disc for avatars and favicons.

## Versions

| File | Use it for |
|---|---|
| `svg/fasospeechcorpora-horizontal.svg` | Main logo: README header, slides, website |
| `svg/fasospeechcorpora-stacked.svg` | Square or tall spaces: posters, title slides |
| `svg/fasospeechcorpora-symbol.svg` | The balafon alone, 48 px and up |
| `svg/fasospeechcorpora-symbol-small.svg` | The balafon alone, 24 to 47 px (fewer keys, no mallets) |
| `svg/fasospeechcorpora-seal.svg` | Round avatar: GitHub, Hugging Face, social profiles |
| `svg/fasospeechcorpora-seal-small.svg` | Favicon and anything under 32 px |
| `svg/fasospeechcorpora-wordmark.svg` | The name alone, when the symbol is already on the page |

Each logo comes in colour, `-reversed` (for dark backgrounds), `-black` and `-white`. PNG exports are in `png/` and the website icon set is in `web/`.

The letters of the name are custom shapes, not a font. Use the files instead of retyping "FasoSpeechCorpora".

## Clear space

Leave empty space around the logo at least as wide as one mallet head. The space grows and shrinks with the logo.

## Minimum size

| Version | Screen | Print |
|---|---|---|
| Horizontal | 120 px wide | 30 mm wide |
| Symbol | 48 px (use `symbol-small` from 24 px) | 12 mm |
| Seal | 32 px (use `seal-small` below) | 8 mm |

## Colours

| Name | HEX | RGB | CMYK | Used for |
|---|---|---|---|---|
| Frame | `#4A2E17` | 74 46 23 | 0 38 69 71 | Frame, mallets, "Vox" |
| Key | `#B0723A` | 176 114 58 | 0 35 67 31 | Keys, "Faso" |
| Calabash | `#E2B45C` | 226 180 92 | 0 20 59 11 | Gourds only |
| Shea | `#F3E3C3` | 243 227 195 | 0 7 20 5 | Light backgrounds, reversed frame |
| Night | `#1E140C` | 30 20 12 | 0 33 60 88 | Dark backgrounds |

Contrast on white: Frame 12.4:1 (fine for any text), Key 3.9:1 (large text only, which covers the wordmark), Calabash 1.9:1 (too light for text, so keep it for the gourds). No Pantone colours have been picked yet. The CMYK values are conversions, so check a printed proof before a print run.

Approved pairs: colour logo on white or Shea; reversed logo on Night or Frame; black or white logo when only one colour is available. On photos, put the logo on a calm area or use the seal.

## Don't

- Stretch, squash, tilt or mirror the logo.
- Change the colours or swap them between parts.
- Add shadows, outlines, gradients or textures.
- Move the symbol and name apart, or resize one without the other.
- Remove keys or gourds from the full symbol. Use the small versions instead.

## Files and sources

The SVG masters were generated by `source/build_real.py` and `source/build_kit.py`, and their strokes were converted to filled shapes. To change the drawing, edit those scripts rather than the SVGs by hand.
