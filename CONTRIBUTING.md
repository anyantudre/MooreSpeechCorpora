# Contributing to FasoSpeechCorpora 🇧🇫

Thank you for being here!

This project is for *everyone* who wants to see Mooré, Dioula, Fulfuldé, Gourmantchéma and other under-served languages represented in speech and language technologies. There are **no strict rules** for contributing! Just a shared mission to advance our languages through open-source collaboration.

Feel free to:
- Suggest **ideas or improvements**
- Open **pull requests**
- Add **a language file or a recipe** (see the README)
- Add **a new source** (one class in `src/fasospeechcorpora/sources/`)
- Improve **existing code or documentation**

✅ Just make sure your contribution works and has been tested:

```bash
pip install -e ".[dev]"
pytest -m "not slow"
```

Together, let’s build something that makes our languages shine in the AI world. 💛
